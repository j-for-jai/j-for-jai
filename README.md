## What I'm working on

- **Cutting LLM cost in production.** Replayed real traffic on 10+ models and moved job-fit scoring from Claude Sonnet to GLM-5, taking cost per call from $0.0103 to $0.0027 (**-73%**). A linear-regression score calibration kept decisions consistent: decision agreement went from 74.8% to 87.6%.
- **Agentic features.** An autonomous job agent, plus a Google OAuth and calendar system exposed to a mail agent as an MCP tool.
- **Multi-agent systems.** LangGraph pipelines, RAG, and A2A / MCP agent meshes.
